# Cresto（自用版）

基于 [Nevodev/Cresto](https://github.com/Nevodev/Cresto)（Apache License 2.0）修改的待办 Android 应用。这个仓库只用来发布安装包，不是原作者的官方发布。

## 下载

到 [Releases](https://github.com/Sure-Will/Cresto-Releases/releases/latest) 下载最新的 `Cresto-<版本名>-<版本号>.apk`。

- 系统要求：Android 11 及以上，arm64 设备
- 包名 `com.sure.cresto`，可以和原版 Cresto 同时安装，数据不互通
- 每个版本附带 `.sha256` 校验文件
- 安装后，App 可在启动时自动检查更新，并在应用内一键升级
